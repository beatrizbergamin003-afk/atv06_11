Atividade de Apropriação: Função das Tags de Tabela

Tag / Atributo Função
<table> Define a estrutura principal da tabela.
<tr> Define uma linha da tabela (Table Row).
<th> Define uma célula de cabeçalho (Table Header), com texto em negrito e centralizado por padrão.
<td> Define uma célula comum de dados (Table Data).
colspan Atributo para mesclar colunas horizontalmente.
rowspan Atributo para mesclar linhas verticalmente.
