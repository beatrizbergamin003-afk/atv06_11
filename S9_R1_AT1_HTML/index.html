Atividade de Apropriação: Atributos HTML5

Atributo Função
required Torna o preenchimento do campo obrigatório antes do envio do formulário.
minlength Define a quantidade mínima de caracteres permitida.
maxlength Define a quantidade máxima de caracteres permitida.
min Define o valor numérico ou data mínima aceita.
max Define o valor numérico ou data máxima aceita.
pattern Aplica uma regra de validação por expressão regular (Regex).
placeholder Exibe um texto explicativo/sugestão enquanto o campo estiver vazio.
